# Help Desk Ticketing System

A Java desktop application designed to provide a centralized system for
creating, assigning, tracking, and resolving IT support tickets.

## Features

- User authentication
- Employee, Technician, and Administrator roles
- Role-based access control
- Create and manage support tickets
- Ticket ownership tracking
- Technician assignment
- Ticket status workflow
- Persistent ticket comments
- SQLite database persistence

## Technologies Used

- Java 21
- JavaFX 21
- Maven
- SQLite
- JDBC
- Eclipse IDE

## Ticket Workflow

Open → In Progress → Resolved → Closed

Resolved tickets can also be reopened and returned to In Progress.
